 Library Management System

## Project Overview
The Library Management System is a Java-based console application designed to manage books and library members. It allows users to add, search, borrow, and return books efficiently.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Serialization

## Features
- Add new books
- View all books
- Search books using Book ID
- Add library members
- Borrow books
- Return books
- Prevent duplicate Book IDs and Member IDs
- Save and load book and member details using file handling
- Maintain book availability and borrowing status

## Project Structure
- Main.java – Main menu and user interaction
- Book.java – Book details and availability
- Member.java – Member details
- LibraryService.java – Library operations and file handling

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java files:

bash
javac *.java


5. Run the application:

bash
java Main
